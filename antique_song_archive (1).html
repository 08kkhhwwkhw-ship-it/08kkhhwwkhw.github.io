GitHub Pages + 실시간 DB 연결 방법

1단계. Firebase 무료 프로젝트 만들기

1) Firebase 콘솔에서 새 프로젝트를 생성합니다.

2) 좌측 메뉴 빌드 > Authentication > Sign-in method에서 익명(Anonymous)을 사용 설정합니다.

3) 좌측 메뉴 빌드 > Firestore Database에서 데이터베이스를 만듭니다.

4) 프로젝트 설정(톱니바퀴)에서 웹 앱(</>)을 추가하고 발급된 firebaseConfig 값을 복사합니다.

2단계. 코드에 내 Firebase 키 붙여넣기

이 HTML 파일의 스크립트 상단에 있는 GITHUB_FIREBASE_CONFIG 객체에 복사한 키 값을 붙여넣습니다.

3단계. GitHub Pages로 무료 웹사이트 공개

1) 파일 이름을 index.html로 저장해 GitHub 저장소(Repository)에 올립니다.

2) 저장소의 Settings > Pages에서 Branch를 main으로 설정하고 Save를 누르면 공유 링크가 생성됩니다!
